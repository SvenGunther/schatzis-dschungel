# Schatzis Dschungel 🌿

Eine kleine Pflanzen-App für Monstera und andere Pflanzenkumpels.

**Öffnen:** https://svengunther.github.io/schatzis-dschungel/

## Was sie kann

- **Heute:** Was heute gegossen, gedüngt, geprüft oder umgetopft werden sollte. Im Winter werden die Gießabstände automatisch länger, und Düngen pausiert bis März.
- **Meine Pflanzen:** Pflanzen mit Foto, Standort und Pflanzentagebuch anlegen. Gießerinnerungen lassen sich als Kalenderdatei (.ics) herunterladen.
- **Angebote:** Aktuelle Monstera-Angebote, eine Wunschliste mit Höchstpreis und ein Preis-Kompass. Die Angebote stehen in `offers.json` und werden jeden Sonntag von Claude aktualisiert.
- **Pflanzendoktor:** Häufige Symptome nachschlagen oder die Frage samt Pflegedaten direkt an Claude schicken.
- **Monstera-Lexikon:** 14 Arten mit Pflege, Schwierigkeit und üblichen Preisen.
- **Umtopfen & Erde:** Anzeichen, Anleitung und eine Aroid-Erdmischung.

## Wo die Daten liegen

Die Pflanzen werden nur im Browser des Geräts gespeichert, nicht auf GitHub. Unter „Meine Pflanzen“ → **Sichern** lässt sich eine Sicherungsdatei herunterladen, und mit **Laden** kommt sie auf ein anderes Gerät.

## Als App aufs Handy

Seite im Browser öffnen, dann **Teilen → Zum Home-Bildschirm** (iPhone) oder **⋮ → App installieren** (Android).
